<h1 align="center">Qwen3.6-Test</h1>
<p align="center">Тест reasoning Qwen 3.6 через OpenRouter.ai</p>

---

Тестовый стенд для проверки reasoning-способностей Qwen 3.6 через OpenRouter.ai. CommonJS, минимальные зависимости.

- **Reasoning** — проверка цепочек рассуждений модели.
- **OpenRouter** — доступ через OpenRouter.ai API.
- **Минимализм** — dotenv + node-fetch, без лишнего.

## Быстрый старт

```bash
git clone https://github.com/AlexanderKuzikov/Qwen3.6-Test.git
cd Qwen3.6-Test
npm install
node index.js
```
